# Retro Password Generator

Retro terminal-themed password generator — inspired by amber CRT aesthetic.

🔗 [Live Demo](https://your-project-name.netlify.app)

## About

A simple password generator built to practice core HTML, CSS, and JavaScript fundamentals. Styled after vintage amber CRT terminals, with a monospace font and terminal-prompt inspired copy.

## Features

- Generates two random 15-character passwords
- Copy-to-clipboard functionality
- Retro terminal-inspired design

## What I Learned

- Using flexbox for consistent, flexible spacing instead of manual margins
- Working with the Clipboard API (`navigator.clipboard.writeText()`)
- Debugging with browser DevTools vs. an in-browser code editor
- Git/GitHub workflow for syncing work across multiple devices
